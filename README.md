# dicts_for_aard2
personal repository of dicts (I made) for Aard2. ~~Automated builds based on Actions are planned.~~

[mw2slob.sh](./mw2slob.sh) is the workflow used for scraping contents from MediaWiki sites to consolidate into these .slob dictionaries. I found it a competent method of preserving MediaWiki sites, so try it out yourself!

Includes:
- ArchWiki
- Gentoo Wiki
- wiki.puella-magi.net
- linux-sunxi.org
- 萌娘百科 (zh.moegirl.org.cn) [dict here](https://github.com/aisuneko/dicts_for_aard2/releases/tag/moegirl-alpha)
- magireco.moe
